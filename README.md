# Scrollport

Scrollport is a virtualisation library for very large lists, tables and grids. It keeps native browser features working, such as find in page, with as little JavaScript as possible. It is at an early stage: the repository holds a demo table and the research spike that measured the limits of native find (`spike/native-find/FINDINGS.md`).

## Run the demo

```sh
npm ci
npm run dev
```
